| 移动 | WASD |
| 闪避 | 空格 |
| 轻攻击 | 鼠标左键 |
| 重攻击 | 鼠标右键 |
| 法术 | 数字键 1-4 |
| 锁定 | Tab |

## 战斗系统

> 战斗是《黑神话：悟空》的核心体验，掌握闪避和法术的时机至关重要。

### 精髓系统

游戏中的**精髓**系统类似于 stamina 机制，所有动作都会消耗精髓：

- **轻攻击连段**：消耗少，适合持续输出
- **重攻击**：消耗大，伤害高，有破防效果
- **闪避**：完美闪避可触发时间减缓

## 初始路线推荐

1. **第一章**：优先探索隐藏区域，收集所有葫芦升级材料
2. **Boss顺序**：建议先挑战较低难度的精英怪积累经验
3. **法术选择**：初期推荐定身术 + 聚形散气组合

> 💡 提示：不要跳过任何NPC对话，部分支线任务的关键信息隐藏在对话中。
