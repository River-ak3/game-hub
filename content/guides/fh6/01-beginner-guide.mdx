## 驾驶操作基础

### 核心操作

| 操作 | 按键（默认） | 说明 |
|------|-------------|------|
| 加速 | RT / W | 油门控制 |
| 刹车 | LT / S | 刹车减速 |

| 转向 | 左摇杆 / AD | 方向控制 |
| 换挡 | 上下拨片 / Shift | 手动挡使用 |
| 氮气加速 | B / N | 加速推进 |
| 回看 | 右摇杆 | 观赏回放 |

### 漂移技巧

漂移是地平线系列的核心驾驶技术：

1. **入弯前减速**：在弯道入口前松开油门轻点刹车
2. **打方向+手刹**：同时拉手刹并打方向盘入弯
3. **反打方向**：漂移过程中反打方向盘维持漂移角度
4. **出弯给油**：漂移结束时松手刹给油出弯

> 💡 不同车辆漂移手感差异很大，日系后驱车（如AE86、RX-7）漂移更加灵活。

## 车辆获取与升级

### 获取方式

1. **赛事奖励**：完成赛事和季节赛可免费获得车辆
2. **车展购买**：使用游戏内CR货币在车展购买
3. **拍卖行**：玩家之间的车辆交易平台
4. **抽奖转盘**：每日抽奖有机会获得稀有车辆
5. **DLC车辆**：跑车通行证每周新增一辆（共30辆）

### 预购奖励

预购玩家可获得**法拉利 J50**作为独家奖励车辆。

### 车辆升级

- **性能升级**：更换引擎、涡轮、刹车、轮胎等提升车辆性能
- **外观改装**：车身套件、涂装、贴花、轮毂等个性化定制
- **调校**：调整悬挂、差速、齿轮比等参数优化驾驶手感

## PC配置需求与优化

### 官方配置要求

| 配置级别 | CPU | 内存 | 显卡 |
|---------|-----|------|------|
| **最低** | i5-8400 / R5 1600 | 16GB | GTX 1650 / RX 6500 XT |
| **推荐** | i7-10700 / R7 5800 | 16GB | RTX 3070 / RX 6800 |
| **极致** | i9-13900K / R9 7950X | 32GB | RTX 5070 Ti |

### 画面优化建议

1. **DLSS 4.5支持**：NVIDIA显卡开启DLSS可大幅提升帧数
2. **动态多帧生成**：RTX 50系列可开启6倍帧生成
3. **1080P 60帧**：最低配置即可流畅运行
4. **国内网络优化**：服务器在海外，建议使用加速器减少延迟

## 新手常见问题

### 游戏卡顿怎么办？
- 更新显卡驱动至最新GeForce Game Ready驱动
- 开启DLSS提升帧数
- 降低阴影和反射画质

### 网络延迟高怎么办？
- 使用网络加速器
- 选择离线模式体验单人内容

### 如何快速赚CR？
- 完成季节赛和每日挑战
- 参与高风险高回报赛事
- 拍卖行低买高卖

## 总结与提示

1. 新手先完成教学关卡和初期赛事，熟悉操作手感
2. 日本地图风景优美，多探索可以发现隐藏奖励
3. 跑车通行证每周更新新车，持续关注
4. 日系车是本作亮点，AE86、GT-R、Supra等经典JDM车不可错过
5. PC端配置要求亲民，GTX 1650即可畅玩1080P
6. 尊享版可提前4天体验，首发加入XGP，性价比很高
