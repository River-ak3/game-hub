## 简介

《极限竞速：地平线6》PC版已经发布，本作对硬件的优化表现相当不错，GTX 1650级别的显卡就能跑1080P 60帧。但如果你想要更好的画面和帧数体验，合理的配置和优化是必不可少的。本篇指南将帮你从硬件选择到游戏内设置全面优化PC体验。

## 官方配置需求

### 最低配置（1080P 30帧）

| 硬件 | 要求 |
|------|------|
| CPU | Intel i5-8400 / AMD Ryzen 5 1600 |
| 内存 | 16GB DDR4 |
| 显卡 | NVIDIA GTX 1650 / AMD RX 6500 XT / Intel Arc A380 |
| 存储 | SSD（必须） |
| 系统 | Windows 10 64位 |

| 硬件 | 要求 |
|------|------|

| 内存 | 16GB DDR4 3200MHz+ |
| 显卡 | NVIDIA RTX 3070 / AMD RX 6800 XT |
| 存储 | SSD 50GB+ |

### 极致配置（4K 60帧+）

| 硬件 | 要求 |
|------|------|
| CPU | Intel i9-13900K / AMD Ryzen 9 7950X |
| 内存 | 32GB DDR5 6000MHz+ |
| 显卡 | NVIDIA RTX 5070 Ti / RTX 5080 |

> 💡 **好消息**：最低配置即可稳跑1080P 60帧，对中低端PC非常友好。GTX 1650在1080P中低画质下平均帧数超过60帧。

## 画面设置优化

### 画质设置建议（按优先级）

| 设置项 | 推荐值 | 性能影响 | 说明 |
|--------|--------|---------|------|
| 分辨率 | 1080P / 1440P | 高 | 根据显示器选择 |
| 抗锯齿 | TAA / DLSS | 中 | N卡优先选DLSS |
| 动态分辨率 | 关 / 50% | 低 | 帧数不够时开启 |
| 世界细节 | 高 | 中 | 影响建筑和植被密度 |
| 环境贴图 | 中 | 中 | 影响反射质量 |
| 光影 | 高 | 高 | 影响整体画面 |
| 阴影 | 中 | 高 | 阴影对帧数影响大 |
| 粒子效果 | 中 | 低 | 雨滴、烟尘等 |
| 纹理质量 | 超高 | 低 | SSD加载无压力 |
| 运动模糊 | 关 / 低 | 低 | 个人偏好 |
| 景深 | 关 | 低 | 竞速时建议关闭 |
| 毛玻璃效果 | 关 | 低 | 对性能有影响 |

### 1080P 60帧优化方案（中低端配置）

如果你的显卡是GTX 1650 / RTX 2060级别：

1. 分辨率设为1080P
2. 世界细节：中
3. 环境贴图：低
4. 光影：中
5. 阴影：低（影响最大）
6. 粒子效果：中
7. 纹理质量：高（SSD无压力）
8. 关闭运动模糊和景深
9. 开启动态分辨率50%

## DLSS设置与帧数提升

### DLSS 4.5支持

FH6支持NVIDIA最新的DLSS 4.5技术：

| DLSS模式 | 帧数提升 | 画面质量 | 适用场景 |
|---------|---------|---------|---------|
| DLSS 超分辨率 质量 | ~1.5倍 | 接近原生 | 平衡画质和性能 |
| DLSS 超分辨率 平衡 | ~1.8倍 | 轻微下降 | 推荐1080P使用 |
| DLSS 超分辨率 性能 | ~2倍 | 明显下降 | 4K低帧时使用 |
| DLSS 动态多帧生成 | 最高6倍 | 取决于基准帧 | RTX 50系列专属 |

### RTX 40系列优化

- 开启DLSS 3.0帧生成，在基准30帧时可提升至60帧
- 建议DLSS质量模式+帧生成开启
- 配合NVIDIA Reflex降低输入延迟

### RTX 50系列优化

- 升级至DLSS 4.5动态多帧生成
- 6倍帧生成模式可让低配显卡也能跑高帧
- 建议从多帧生成2倍开始，逐步调整

## 显卡驱动更新

### NVIDIA用户

1. 下载最新的 **GeForce Game Ready 驱动**（已针对FH6优化）
2. 在NVIDIA控制面板中设置FH6为"最高性能优先"
3. 开启G-Sync（支持的话）

### AMD用户

1. 更新至最新 **AMD Adrenalin 驱动**
2. 开启Radeon Super Resolution（FSR等效）
3. 启用AMD Anti-Lag降低延迟

## 国内网络优化

FH6的服务器在海外，国内玩家可能遇到网络问题：

### 加速器推荐

| 问题 | 解决方案 |
|------|---------|
| 登录失败/超时 | 使用游戏加速器（UU/雷神/迅游等） |

| 社交功能加载慢 | 加速Xbox Live服务 |

如果不想折腾网络，可以使用离线模式体验单人内容：
- 在Xbox应用中设置离线登录
- 离线模式无法使用联机功能和赛季奖励

## 常见问题解决

### 卡顿/掉帧

1. **更新显卡驱动**至最新Game Ready版本
2. **关闭后台程序**（浏览器、下载工具等）
3. **降低阴影和光影**画质设置
4. **确认使用SSD**而非HDD
5. **开启DLSS**（NVIDIA显卡）
6. **检查Windows电源计划**，设为"高性能"

### 掉线/连接失败

1. 使用加速器连接
2. 检查防火墙设置
3. 重启路由器
4. 尝试离线模式

### 闪退/崩溃

1. 更新显卡驱动
2. 验证游戏文件完整性
3. 关闭超频（CPU/GPU）
4. 检查DirectX运行时是否最新
5. 以管理员身份运行

### 黑屏/无画面

1. 切换全屏/窗口模式
2. 检查显示器分辨率和刷新率
3. 更新显卡驱动
4. 删除本地配置文件重新生成

## 总结与提示

1. **最低配置很亲民**，GTX 1650+SSD就能流畅玩
2. **DLSS是帧数救星**，N卡用户务必开启
3. **阴影是最大的帧数杀手**，优先降低
4. **国内玩家使用加速器**解决网络问题
5. **RTX 50系列升级DLSS 4.5**可体验6倍帧生成
6. 遇到问题先更新驱动，再调画质，最后考虑硬件升级
