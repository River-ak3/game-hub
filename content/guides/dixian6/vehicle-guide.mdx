## S级车辆推荐

### 1. 战争行者

| 属性 | 数值 |
|------|------|
| 速度 | 98/100 |
| 护甲 | 95/100 |
| 机动性 | 72/100 |
| 特殊能力 | 磁力抓取 |

**获取方式**：完成主线任务「第一次接触」后，在西域营地的商人处购买。

> 战争行者是游戏中最均衡的战斗座驾，适合大多数战斗场景。

### 2. 天穹之翼

| 属性 | 数值 |
|------|------|
| 速度 | 100/100 |
| 护甲 | 60/100 |
| 机动性 | 95/100 |
| 特殊能力 | 空中滑翔 |

**获取方式**：在「天空墓地」副本中击败最终Boss后概率掉落（掉率 15%）。

## A级车辆推荐

### 迅影摩托

- **优势**：超高机动性，适合探索和逃脱
- **劣势**：护甲低，不适合正面战斗
- **获取**：开局即可获得

> 💡 提示：迅影摩托在早期探索中非常实用，建议优先升级其续航能力。

## 车辆升级优先级

1. **引擎** - 提升最高速度
2. **护盾** - 增加生存能力
3. **武器** - 提升战斗输出
4. **特殊装备** - 根据使用场景选择
