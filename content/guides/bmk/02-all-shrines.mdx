## 简介

土地庙是《黑神话：悟空》中的存档点和传送系统，相当于其他游戏中的篝火或传送门。激活土地庙后可以传送回已访问过的任意土地庙，极大方便了探索和刷怪。本篇攻略汇总了全六章（含隐藏章节）的所有土地庙位置，确保你不会遗漏任何一个传送点。

## 第一回·黑风山

黑风山是游戏的开篇章节，地形以山林和寺庙为主，土地庙分布较为密集。

### 黑风洞

| 土地庙名称 | 位置描述 |
|-----------|---------|
| 洞内 | 进入黑风洞后的第一个存档点 |

### 隐藏地图：隐·旧观音禅院

> ⚠️ **特殊条件**：需要先敲响三口钟才能进入。

三口钟的位置：
1. 击败**广智**后，BOSS战不远处的凉亭内
2. 击败**广谋**后，BOSS战不远处的凉亭内
3. **白衣秀士**附近左侧山涧的凉亭

敲响三口钟后会被传送到旧观音禅院隐藏地图，这里有一个特殊的土地庙：**隐·旧观音禅院**。

## 土地庙功能一览

| 功能 | 说明 |
|------|------|
| 调息 | 恢复全部生命值和法力值 |
| 铸造 | 升级和强化武器 |
| 打坐 | 切换已装备的法术技能 |
| 行囊 | 管理物品、装备和精魄 |
| 拾遗 | 补取之前遗漏的精魄 |
| 传送 | 快速传送到其他已激活的土地庙 |
| 返回 | 返回上一章节的最后一个土地庙 |

## 总结与提示

1. **每到一个新区域优先激活土地庙**，这样即使战斗失败也不用跑远路
2. **隐藏地图的土地庙容易遗漏**，特别是第一回的旧观音禅院需要敲三口钟
3. **土地庙的拾遗功能**非常重要，前期如果没有葫芦无法吸收精魄，后期可以在任意土地庙补取
4. **传送功能让你可以随时返回刷材料或找遗漏的道具**
5. **BOSS战前记得在附近土地庙调息**，确保满状态进入战斗
6. 花果山的土地庙需要在完成主线特定条件后才能解锁
